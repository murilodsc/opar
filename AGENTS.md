Contexto do Projeto:
Atue como um desenvolvedor Front-end Senior especializado em Next.js e Acessibilidade. Estou desenvolvendo uma Landing Page voluntária para a ONG OPAR (Organização de Proteção Animal de Resgate) de São José dos Campos. O objetivo é substituir o site atual (oparsjc.org) por uma versão moderna, rápida e acessível para dispositivos móveis, focando em facilitar reencontros de animais perdidos e arrecadar doações.

Stack Técnica:

Framework: Next.js 14+ (App Router)

Estilização: Tailwind CSS

Ícones: Lucide React

Imagens: Componente next/image (otimizado)

Linguagem: TypeScript

Requisitos de Negócio (Seções da Página):

Hero Section: Headline de impacto emocional, foto de alta qualidade de um pet e dois botões de Call-to-Action (CTA) claros: "Perdi meu Pet / Encontrei um Animal" e "Quero Adotar".

Sobre a OPAR: Seção de texto limpa explicando a missão de resgate e proteção.

Galeria de Animais (Mockup): Grid de cards para animais em destaque (nome, porte, idade e status).

Como Ajudar (Seção Pix): Área visualmente destacada com informações de doação (Chave Pix) e um botão "Copiar Chave Pix".

FAQ de Resgate: Acordeão com perguntas comuns sobre o que fazer ao encontrar um animal.

Rodapé: Contatos, redes sociais e endereço em SJC.

Diretrizes de Engenharia e Acessibilidade (Pilar de Ciência da Computação):

WCAG Compliance: Garanta contraste de cores adequado e uso correto de tags semânticas (<header>, <main>, <section>, <footer>, <h1>-<h6>).

Aria-Labels: Todos os botões e links devem ter descritivos para leitores de tela.

Responsividade: Design Mobile-First (essencial para quem está na rua com o animal).

Clean Code: Componentize elementos repetitivos (Cards, Botões, Títulos).

SEO: Configure o objeto metadata para o Next.js com título, descrição e OpenGraph.

Tarefa:
Desenvolva o código completo para a página principal (page.tsx) e os componentes necessários. Utilize cores que remetam ao cuidado animal (azuis, verdes ou cores da marca original se forem harmoniosas). Use dados fictícios (placeholder) para os animais, mas mantenha a estrutura pronta para receber uma API futuramente.
